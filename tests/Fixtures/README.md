# Test fixtures

Every test image is synthetic: gradients and simple shapes, so there's no third-party content.
All of them are generated by `generate.sh`:

| Images | How they are made |
|---|---|
| Inputs (`*/Resources/**/01.*`, `03.jpg`, `04.png`, `ImageReaderTest/02.png`, `03.gif`) | Drawn with GD by `generate-images.php inputs` |
| `FlipTest/02.png`, `FlipTest/03.png` | ImageMagick `-flop` / `-flip`, independent of the library |
| `ImageReaderTest/05-animated.webp` | ImageMagick, 3 frames (GD can't decode animated WebP, which is what the test checks) |
| `DistortionTest/02.jpg`, `ImageTest/02.png`, `ImageTest/05.png`, `ImageTest/03.webp` | Snapshots of the library's own output (`generate-images.php expected`) |
| `photo-with-metadata.jpg` | GD and exiftool, with fictional EXIF, IPTC and XMP metadata |

Regenerate snapshots only after an intended change in output, and check the new images by eye.
If you change the metadata, also update the expected values in `tests/FunctionalTest/Metadata/Parser/`.
